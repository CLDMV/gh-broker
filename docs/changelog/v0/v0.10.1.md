# gh-broker v0.10.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/0.10.1`

---

## Overview

v0.10.1 fixes two problems found on the first live runs of v0.10.0. The OTP gate now says why it refused a code, so an agent can tell you the code was wrong (and how close it is to a lockout) instead of just asking for another one. `report_dependents` no longer fails with GitHub's raw 502 page when it lists `dev` branches on a large org.

No configuration changes. The gate's rules (what counts as a bad code, lockouts, windows) are unchanged; only its messages are new.

---

## 🐛 Bug Fixes

### The OTP gate says why it refused a code ([#154](https://github.com/CLDMV/gh-broker/pull/154))

A wrong code used to get the same answer as a missing one, `OTP required for <tool>: ask the user for a current code…`, so the agent couldn't tell the code had been rejected. Fixes [#152](https://github.com/CLDMV/gh-broker/issues/152).

- **Wrong, expired or malformed code:** `OTP code for <tool> was not accepted (1 of 5 bad codes before a lockout of 10 minutes)`, asking for a fresh code. The count is the same one `otp_status` already shows that agent.
- **The bad code that starts a lockout** says so, with how long it lasts. The one that starts a hard lock names the `gh-broker otp unlock` command to run.
- **A real code whose time step is already spent** (reused, or older than the last code used): `OTP code for <tool> is spent (it, or a newer code, was already used)`, asking for the next code. It still doesn't count as a bad code.
- A missing code keeps the old message.

Lockout lengths that aren't whole minutes are given in seconds (`lockoutSeconds: 90` reads "90 seconds").

### `report_dependents` no longer gets a 502 listing dev branches ([#155](https://github.com/CLDMV/gh-broker/pull/155))

The dev-branch pass asked GitHub for 100 repositories per GraphQL page, each with the full `package.json` text on both the default branch and `dev`. On the CLDMV org GitHub timed out, and the call failed with the raw nginx `502 Bad Gateway` page. Fixes [#153](https://github.com/CLDMV/gh-broker/issues/153).

- Pages are now 25 repositories.
- A page that gets a 502, 503 or 504 is retried at half the size, down to 5, and keeps the smaller size for the rest of the listing.
- If the smallest page still times out, the result comes back with what was found, `truncated: true` and the new `truncatedReason: "github-timeout"`.

## Upgrade notes

- No breaking changes. Upgrade with `sudo npm install -g --prefix /usr/local --ignore-scripts @cldmv/gh-broker@latest` and `sudo gh-broker install`, then restart Claude sessions (or `/mcp` reconnect) so they pick up the restarted broker.
- Anything that matched the old `OTP required` text for a wrong code should match the new messages instead; a missing code still gets `OTP required`.

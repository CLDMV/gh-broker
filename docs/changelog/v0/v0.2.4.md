## 🔧 CI & tooling

### Sign redirected security PRs ([#41](https://github.com/CLDMV/gh-broker/pull/41))

The hotfix-redirector now maps the `CLDMV_BOT_*` GPG secrets so that security PRs it redirects are GPG-signed (and therefore "Verified"), instead of landing unsigned and being blocked by the verified-signature merge rule (`e754c70`).

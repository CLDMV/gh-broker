# gh-broker v0.16.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `hotfix/0.16.1`

---

## Overview

v0.16.1 fixes the node download that `install` and `upgrade` fall back to when the box has no root-owned qualifying node. In v0.16.0 it asked `tar` for the wrong path inside the archive and the install stopped at the node step.

---

## 🐛 Bug Fixes

### The node download extracts the right member ([#256](https://github.com/CLDMV/gh-broker/issues/256))

The member path was built from the tarball's file name (`node-v26.13.1-linux-x64.tar.xz/bin/node`). The archive's top folder is the name without `.tar.xz`, so `tar` found nothing and `install` failed with `Not found in archive`. It now asks for `node-v26.13.1-linux-x64/bin/node`. A new test runs the real `tar` against a nodejs.org-shaped tarball, since the old one mocked `tar` and pinned the same wrong path.

A failed v0.16.0 install stopped before the service unit, the MCP entries and the app were touched, so the daemon kept running the previous version.

Fixes [#256](https://github.com/CLDMV/gh-broker/issues/256).

## 🐛 Bug Fixes

### Route the Required PR Check mirror to `cldmv-runners` on private repos ([#22](https://github.com/CLDMV/gh-broker/pull/22))

The local `✅ Required PR Check` mirror job is routed to the self-hosted `cldmv-runners` on private repos, so the required check actually runs (and posts) where GitHub-hosted runners aren't used — otherwise the ruleset's required check never reports and the PR can't merge (`13a4e1b`).

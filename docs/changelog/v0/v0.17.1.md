---

## 🐛 Bug Fixes

### A pane on the connect bridge isn't reported as skipped ([#267](https://github.com/CLDMV/gh-broker/pull/267))

Since v0.17.0, a pane already on the connect bridge printed `skipped (already on the connect bridge)`, while the summary line didn't count it as skipped. Nothing needed doing for that pane, so it now prints `on the connect bridge (nothing to do)`. "Skipped" is kept for panes that needed `/mcp reconnect` and didn't get it.

Resolves [#266](https://github.com/CLDMV/gh-broker/issues/266).

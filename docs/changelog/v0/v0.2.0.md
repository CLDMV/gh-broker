# gh-broker v0.2.0 Changelog

**Release Date**: August 2026
**Release Type**: Minor
**Branch**: `release/0.2.0`

---

## Overview

The first substantive release of the credential-routing MCP broker. GitHub reads — and the first writes — are routed through the daemon so the agent acts without ever holding a token, with per-owner read/write PATs resolved by repo owner and mode. Shipped in [#5](https://github.com/CLDMV/gh-broker/pull/5).

---

## ✨ Features

- **Custom review-thread verbs** — `resolve_review_thread` / `reply_review_thread`, so a PR review thread (e.g. Copilot's) can be replied to or resolved via the GraphQL mutations on the write PAT, filling a gap the hosted MCP has no tool for (`7a47c21`).
- **`create_pull_request` allowlisted; `deploy-app.sh` syncs `config.json`** (`8ce78f7`).

## 🐛 Bug Fixes

- **All-toolsets upstream** — route to the all-toolsets hosted MCP and skip allowlisted tools the upstream doesn't expose, so the advertised toolset matches what actually resolves (`8f4302d`).

## 🔧 Other

- `link_issue` disabled in the allowlist as dead (`92b3840`); the `link_issue` path refactored to the Octokit SDK + `@octokit/auth-app` App token instead of hand-rolled fetch (`4c1e88f`).

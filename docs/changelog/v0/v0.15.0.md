# gh-broker v0.15.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `release/0.15.0`

---

## Overview

v0.15.0 adds `--wait` to `agent reconnect` and `upgrade`, so sessions that were busy with a dialog or half-typed input get reconnected once they're clear instead of needing a rerun. It also fixes the version `npm_scaffold` reports on a resumed call, picks up the `@hono/node-server` security fixes, and adds the fleet's lint and format setup.

---

## ✨ Features

### `agent reconnect --wait` ([#244](https://github.com/CLDMV/gh-broker/pull/244))

`sudo gh-broker agent reconnect --wait 5m` (any time from `1s` to `30m`, e.g. `90s`) holds back the panes it would otherwise skip because of text in the input box, a dialog, or a change between the check and the send. It re-checks them every 5 seconds and sends `/mcp reconnect` to each as soon as it's clear. Panes still blocked when the time is up are skipped as before, with how long it waited. A pane that disappears is dropped, and a tmux call that times out is retried on the next round. `--dry-run` never waits.

`sudo gh-broker upgrade --wait 5m` passes it to its reconnect step, and the "finish by running" line includes it. `--wait` together with `--no-reconnect` is refused.

Resolves [#235](https://github.com/CLDMV/gh-broker/issues/235).

## 🐛 Bug Fixes

### `npm_scaffold` reports the placeholder version it found ([#243](https://github.com/CLDMV/gh-broker/pull/243))

On a resumed call `npm_scaffold` returned `"version": "0.0.1-placeholder"`, the constant, even when the registry held something else. It now reports the placeholder versions actually on the registry, comma-separated (e.g. `0.0.0-stage, 0.0.1-stage`). A first publish still reports the version it published.

Fixes [#198](https://github.com/CLDMV/gh-broker/issues/198).

## 🔧 CI & tooling

### Lint and format ([#246](https://github.com/CLDMV/gh-broker/pull/246))

The repo now has the fleet's lint and format setup: `lint`, `lint:fix`, `format` and `format:check` scripts, the base prettier and eslint configs in `.configs/` with a `typescript-eslint` block for the TS sources, `.prettierignore`, and the pre-commit hook in `.githooks/`. `build:ci` runs lint and the format check before the build. Prettier reformatted the existing code. The lint fixes were small: wrapped errors keep the original as `cause` where it can't hold credentials, and unused imports and parameters were removed. Nothing changes at runtime.

Fixes [#187](https://github.com/CLDMV/gh-broker/issues/187).

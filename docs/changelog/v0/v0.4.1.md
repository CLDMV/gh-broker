# gh-broker v0.4.1 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

v0.4.1 keeps the toolchain current and adopts the shared CLDMV file-header setup. Runtime dependencies move by one patch (`@modelcontextprotocol/sdk` 1.30.0 to 1.30.1), TypeScript goes back to 6, and every source, test and workflow file now carries a uniform header maintained by `@cldmv/fix-headers`. No broker behavior changed.

---

## 🔧 CI & tooling

### Uniform file headers with `@cldmv/fix-headers` ([#84](https://github.com/CLDMV/gh-broker/pull/84))

The repository adopts the shared CLDMV header configuration. `@cldmv/fix-headers` 2.1.1 and `@cldmv/configs` 1.2.0 are new dev dependencies, `.configs/fix-headers.json` holds the checked-in config, and a new `npm run fix:headers` script restamps headers. Every file under `src/`, `tests/`, `deploy/` and `.github/workflows/` was restamped in one pass, which is why the diff touches more than fifty files. The change is comments only.

## 🔧 Dependencies

- TypeScript is back on 6.0.3 ([#82](https://github.com/CLDMV/gh-broker/pull/82)). TypeScript 7 is not usable here until 7.1 ships a compiler API.
- The patch group ([#80](https://github.com/CLDMV/gh-broker/pull/80)): `@modelcontextprotocol/sdk` 1.30.0 to 1.30.1, `@types/node` 26.6.2 to 26.6.3, and `vitest` and `@vitest/coverage-v8` 5.0.1 to 5.0.2 (both dev-only).

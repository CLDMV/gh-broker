# gh-broker v0.3.3 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

v0.3.3 is a packaging-only release. The package's `publishConfig.access` changes from `restricted` to `public`, so the scoped `@cldmv/gh-broker` package is published as a public package. It shipped through the hotfixes lane ([#72](https://github.com/CLDMV/gh-broker/pull/72)). No runtime code changed.

---

## 🐛 Bug Fixes

### Publish as a public scoped package ([#72](https://github.com/CLDMV/gh-broker/pull/72))

`package.json` declared `"publishConfig": { "access": "restricted" }`, which is the setting for a private scoped package and makes the registry treat a publish of `@cldmv/gh-broker` as one. It is now `"public"`.

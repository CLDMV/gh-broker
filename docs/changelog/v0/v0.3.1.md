# gh-broker v0.3.1 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Branch**: `release/0.3.1`

---

## Overview

Toolchain-floor fix: `vitest` 5 requires Node `^20.19.0 || >=22.12.0`, which excludes plain `>=20.19.0`/`>=20`-style ranges that don't also cover the 22.x break point. Raises the real floor to match, in both the installer's own Node-version check and `package.json` `engines.node`.

---

## 🐛 Bug Fixes

- Installer's Node-version prerequisite check raised to `>=22.12.0`, matching what `vitest` 5 actually requires — a lower floor there let the installer proceed on a Node version the test toolchain can't run on.
- `engines.node` raised to `>=22.12.0` for the same reason.

---

## 🔧 Dependencies

- `vitest`, `@vitest/coverage-v8`, `@octokit/auth-app`, `@types/node` bumped to their latest compatible versions (#52).

---

## Upgrade notes

No breaking changes to the broker's runtime behavior — this only affects the Node version required to build/test/install it.

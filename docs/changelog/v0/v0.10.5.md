# gh-broker v0.10.5 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/0.10.5`

---

## Overview

v0.10.5 fixes `npm_scaffold`, which npm had started refusing. The registry now rejects any version whose core is `0.0.0`, so the `0.0.0-stage` placeholder failed with HTTP 403. The placeholder is now `0.0.1-stage`.

The release also carries the first internal refactors toward the public core library ([#175](https://github.com/CLDMV/gh-broker/issues/175)): the OTP state helpers, config validation and the TOTP step each have one implementation now. Tools, routing, the OTP gate and the installer behave as before.

---

## 🐛 Bug Fixes

### `npm_scaffold` publishes `0.0.1-stage` ([#184](https://github.com/CLDMV/gh-broker/pull/184))

npm answered the placeholder publish with `403 You cannot publish using the version: 0.0.0-stage`, so the verb couldn't create a new package at all. The placeholder is now `0.0.1-stage`. It is still a prerelease, so it sorts below every real release and can't take a real `0.0.1`.

A package scaffolded by an earlier release keeps its `0.0.0-stage` placeholder. That only matters for resuming an interrupted scaffold, and the earlier placeholders all finished both steps.

Fixes [#186](https://github.com/CLDMV/gh-broker/issues/186).

---

## 🔧 Refactoring

### First steps toward the core library ([#182](https://github.com/CLDMV/gh-broker/pull/182))

- The OTP state-file helpers live in one place, `src/otp/state.ts`, instead of being repeated in the CLI.
- The CLI's base32 encoder is gone. It uses the one in `src/otp/totp.ts`, and the TOTP step and the state-path default are each defined once.
- Config validation is split into the part a library host needs (`parseConfigLib`) and the daemon's own part.
- The window text for OTP refusals moved from the gate to the gating-policy module.
- `AuditEntry` moved to the shared types, next to a new `SecurityEvent` union for the library's security-event sink.

None of these change behaviour. The new tests cover the split config parser and the shared state helpers.

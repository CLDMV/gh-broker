# gh-broker v0.16.2 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/0.16.2`

---

## Overview

v0.16.2 is a small cleanup after the `connect` bridge. `agent add` no longer saves `--claude-config` folders for an agent it then refuses to register, and two internal pieces follow the bridge's patterns.

---

## 🐛 Bug Fixes

### `agent add` refuses before it saves anything ([#255](https://github.com/CLDMV/gh-broker/pull/255))

`sudo gh-broker agent add <user> --claude-config <dir>` with the bridge binary missing used to save the folders before refusing. That left folders remembered for an agent that was never registered, and `agent remove` couldn't clear them because the agent didn't exist. The binary check now runs first, so a refused add writes nothing. `agent sync` keeps its current order on purpose: the agent is already registered there, so the saved folders are used on the next sync.

Resolves [#252](https://github.com/CLDMV/gh-broker/issues/252).

---

## 🔧 CI & tooling

- The smoke test's socket reader frames lines with a chunk array and decodes UTF-8 across reads, like the bridge ([#255](https://github.com/CLDMV/gh-broker/pull/255)).
- The bridge's pending-answer expiry test waits for the `list_changed` notification instead of a fixed sleep ([#255](https://github.com/CLDMV/gh-broker/pull/255)).

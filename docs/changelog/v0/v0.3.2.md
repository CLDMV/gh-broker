# gh-broker v0.3.2 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Branch**: `release/0.3.2`

---

## Overview

Follow-up to v0.3.1's Node-floor raise: brings the CI test matrix itself up to the same `>=22.12.0` floor so it actually exercises the versions the toolchain requires, and groups related Dependabot updates so they land as one PR instead of several.

---

## 🔧 CI & tooling

- CI test matrix bumped to match the `>=22.12.0` engines floor raised in v0.3.1.
- Dependabot config groups the `eslint`/`prettier` families and the `vitest`/`@vitest/*` family into one bump each, instead of a separate PR per package.

---

## Upgrade notes

No breaking changes — CI/tooling only, no runtime code changed.

# gh-broker v0.10.7 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/0.10.7`

---

## Overview

v0.10.7 lets `npm_scaffold` finish a package whose staged placeholder went live late. The only runtime change is in `npm_scaffold`.

---

## 🐛 Bug Fixes

### `npm_scaffold` resumes when a staged placeholder went live later ([#195](https://github.com/CLDMV/gh-broker/pull/195))

The `0.0.1-stage` placeholder that v0.10.5 published for `@cldmv/lib-otp` did go live in the end, next to npm's own `0.0.0-stage` staging placeholder. v0.10.6 only resumed on a package holding exactly one `0.0.1-placeholder` version, so it refused the package as "not created by npm_scaffold" and the trusted publisher could not be added.

The resume check now accepts a package whose versions are all `0.0.0-…`/`0.0.1-…` prereleases marked `scaffoldedBy: "gh-broker"`, plus npm's `0.0.0-stage` if present, with at least one of ours. Every placeholder's recorded repository must match the call. A real release, or npm's placeholder on its own, is still refused.

Fixes [#194](https://github.com/CLDMV/gh-broker/issues/194).

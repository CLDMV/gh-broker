## Overview

v0.14.1 fixes `gh-broker agent reconnect` skipping nearly every Claude Code session. After the v0.14.0 upgrade it sent `/mcp reconnect` to 1 of 17 panes; the rest stayed disconnected.

---

## 🐛 Bug Fixes

### `agent reconnect` sends to idle and working sessions ([#236](https://github.com/CLDMV/gh-broker/pull/236))

Two things made it skip panes it should have sent to:

- **A prompt suggestion read as typing.** An idle Claude Code session shows a dimmed suggested prompt in its empty input box. That box is `❯` followed by a no-break space, and the detector only recognised `❯` followed by a plain space. It missed the real box, matched an earlier user message higher up the screen and reported the pane as "composer not empty". Panes are now captured with their colour codes (`capture-pane -e`), dimmed text is ignored, and the no-break space counts.
- **Claude working skipped the pane.** Claude Code queues what's typed while it works, so being busy is no longer a reason to skip.

A pane is still skipped when it has real text in its input box, shows a dialog such as a permission prompt or a menu, has no input box on screen, is in copy mode, or has synchronized panes.

Part of [#235](https://github.com/CLDMV/gh-broker/issues/235); its `--wait` retry isn't in this release.
